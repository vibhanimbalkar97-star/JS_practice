# 13. `switch` Statement

`switch` is used when one expression is compared with multiple possible values.

### Syntax

```
switch (expression) {
    case value1:
        // code
        break;

    case value2:
        // code
        break;

    default:
        // code
}
```

Example:

```
let day = 2;

switch (day) {
    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    case 3:
        console.log("Wednesday");
        break;

    default:
        console.log("Invalid day");
}
```

Output:

```
Tuesday
```

## Important rules

### Rule 1: `switch` uses strict comparison

```
let x = "5";

switch (x) {
    case 5:
        console.log("Number");
        break;

    case "5":
        console.log("String");
        break;
}
```

Output:

```
String
```

Because `"5"` and `5` have different types.

### Rule 2: `break` stops execution

```
let x = 1;

switch (x) {
    case 1:
        console.log("A");
        break;

    case 2:
        console.log("B");
        break;
}
```

Output:

```
A
```

Without `break`, execution continues into the following cases. This is called fall-through.

### Trick: Fall-through

```
let x = 1;

switch (x) {
    case 1:
        console.log("A");

    case 2:
        console.log("B");

    default:
        console.log("C");
}
```

Output:

```
A
B
C
```

Why?

- `case 1` matches.
- There is no `break`.
- JavaScript executes the next cases too.

### Rule 3: `default`

`default` executes when no case matches.

It is similar to `else`.

### When to use `switch` vs `if`

\| Use `switch` | Use `if...else` |\
\|---|---|\
\| One value, multiple fixed options | Ranges and complex conditions |\
\| Menu options | Age or marks ranges |\
\| Day, role, status | Multiple comparisons |\
\| Exact matching | `&&`, `||` conditions |
