# 11. Nullish Coalescing `??`

This is a very important modern JavaScript concept.

`??` returns the right side only when the left side is `null` or `undefined`.

```
let username = null;

console.log(username ?? "Guest");
```

Output:

```
Guest
```

### Rule

| Left value  | `value ?? "Default"` |
| ----------- | -------------------- |
| `null`      | `"Default"`          |
| `undefined` | `"Default"`          |
| `0`         | `0`                  |
| `false`     | `false`              |
| `""`        | `""`                 |

### Trick: `||` vs `??`

```
console.log(0 || 100);  // 100
console.log(0 ?? 100);  // 0
```

Why?

- `||` checks truthiness.
- `??` checks only `null` and `undefined`.

### Practical example

```
let quantity = 0;

let result1 = quantity || 10;
let result2 = quantity ?? 10;

console.log(result1); // 10
console.log(result2); // 0
```

If zero is a valid value, `??` is often the better choice.
