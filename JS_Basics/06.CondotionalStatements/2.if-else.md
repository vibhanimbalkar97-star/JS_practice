# 3. `if...else` Statement

Used when there are two possible paths.

```
let age = 16;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
```

Output:

```
Minor
```

### Important rule

Only one of the two blocks executes.

| Condition | Result          |
| --------- | --------------- |
| Truthy    | `if` executes   |
| Falsy     | `else` executes |

### Interview Trick: Assignment vs Comparison

```
let x = 10;

if (x = 5) {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
A
```

Why?

`x = 5` is an assignment expression. It assigns 5 to `x`, and the expression evaluates to 5, which is truthy.

Correct comparison:

```
if (x === 5) {
    console.log("A");
}
```

Use `===` for value and type comparison.
