# 6. Nested `if` Statements

An `if` inside another `if` is called a nested `if`.

Example:

```
let age = 25;
let hasLicense = true;

if (age >= 18) {
    if (hasLicense) {
        console.log("Can drive");
    } else {
        console.log("License required");
    }
} else {
    console.log("Underage");
}
```

Output:

```
Can drive
```

### How to solve nested `if` questions

Read from outside to inside.

1. Check the outer condition.
2. If true, enter the outer block.
3. Check the inner condition.
4. Execute the matching block.
5. Follow indentation/braces to see which `else` belongs to which `if`.

### Trick question

```
let x = 10;

if (x > 5) {
    console.log("A");

    if (x > 15) {
        console.log("B");
    }

    console.log("C");
}
```

Output:

```
A
C
```

Why?

- `x > 5` → true.
- `x > 15` → false.
- `"C"` is inside the outer `if`, not the inner one.

### Important rule: Dangling `else`

An `else` belongs to the nearest unmatched `if`.

```
if (true)
    if (false)
        console.log("A");
    else
        console.log("B");
```

Output:

```
B
```

The `else` belongs to the inner `if`.

Use braces to avoid confusion.
