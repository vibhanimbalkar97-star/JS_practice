# 10. Logical Operators – `&&`, `||`, `!`

These are essential for conditional statements.

\| Operator | Meaning |\
\|---|---|\
\| `&&` | AND |\
\| `||` | OR |\
\| `!` | NOT |

## A. AND `&&`

Both conditions must be truthy for the entire expression to be truthy.

```
let age = 25;

if (age >= 18 && age <= 60) {
    console.log("Eligible");
}
```

Output:

```
Eligible
```

### Rule

If the first operand is falsy, JavaScript does not evaluate the second operand.

```
console.log(false && true); // false
console.log(true && true);  // true
console.log(true && false); // false
```

### Important trick: `&&` returns an operand, not always a Boolean

```
console.log(10 && 20);
console.log(0 && 20);
console.log("Hi" && "Hello");
```

Output:

```
20
0
Hello
```

Why?

- If the first value is falsy → return the first value.
- If the first value is truthy → return the second value.

### Short-circuit example

```
let x = 0;

console.log(x && 10 / x);
```

Output:

```
0
```

No division happens.

## B. OR `||`

If at least one operand is truthy, the expression is truthy.

```
console.log(true || false); // true
console.log(false || false); // false
```

### Important trick: `||` returns an operand

```
console.log(0 || 100);
console.log("Hi" || "Hello");
console.log(null || "Guest");
```

Output:

```
100
Hi
Guest
```

Rule:

- If the first operand is truthy → return the first operand.
- If the first operand is falsy → return the second operand.

### Short-circuit example

```
console.log(true || 10 / 0);
```

Output:

```
true
```

The second operand is not evaluated.

## C. NOT `!`

`!` converts the value to Boolean and reverses it.

| Expression | Result  |
| ---------- | ------- |
| `!true`    | `false` |
| `!false`   | `true`  |
| `!0`       | `true`  |
| `!1`       | `false` |
| `!""`      | `true`  |
| `!"Hello"` | `false` |
| `![]`      | `false` |

### How to solve `!x`

```
let x = 0;

if (!x) {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
A
```

Step-by-step:

1. `x = 0`
2. `0` is falsy.
3. `!0` → `true`.
4. `if` executes.

### Important trick: `!` vs `!==`

```
let x = 5;

console.log(!x);       // false
console.log(x !== 5);  // false
console.log(x !== 0);  // true
```

`!x` means "is x falsy?"

`x !== 5` means "is x not strictly equal to 5?"

They are different.
