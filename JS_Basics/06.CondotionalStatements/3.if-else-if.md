# 4. `if...else if...else`

Used to check multiple conditions.

### Syntax

```
if (condition1) {
    // code
} else if (condition2) {
    // code
} else if (condition3) {
    // code
} else {
    // default code
}
```

Example:

```
let marks = 85;

if (marks >= 90) {
    console.log("A");
} else if (marks >= 80) {
    console.log("B");
} else if (marks >= 70) {
    console.log("C");
} else {
    console.log("Fail");
}
```

Output:

```
B
```

### Rule: First truthy condition wins

JavaScript checks from top to bottom.

As soon as one condition is truthy:

- Its block executes.
- The remaining conditions are skipped.

### Trick: Wrong order

```
let marks = 95;

if (marks >= 50) {
    console.log("C");
} else if (marks >= 75) {
    console.log("B");
} else if (marks >= 90) {
    console.log("A");
}
```

Output:

```
C
```

Why? `marks >= 50` is already true.

Correct order:

```
if (marks >= 90) {
    console.log("A");
} else if (marks >= 75) {
    console.log("B");
} else if (marks >= 50) {
    console.log("C");
} else {
    console.log("Fail");
}
```
