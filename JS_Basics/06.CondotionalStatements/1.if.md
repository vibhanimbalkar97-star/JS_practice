# 2. `if` Statement

### Syntax

```
if (condition) {
    // code executes if condition is true
}
```

Example:

```
let age = 20;

if (age >= 18) {
    console.log("Adult");
}
```

Output:

```
Adult
```

### Rules

1. The condition is written inside `()`.
2. The block is written inside `{}`.
3. If the condition is truthy, the block executes.
4. If the condition is falsy, the block is skipped.
5. Braces are optional for a single statement, but recommended.

Example:

```
if (true)
    console.log("Hello");
```

This works, but prefer:

```
if (true) {
    console.log("Hello");
}
```

### Trick

```
if (10) {
    console.log("A");
}
```

Output:

```
A
```

Why? JavaScript converts `10` to a truthy value when evaluating the condition.
