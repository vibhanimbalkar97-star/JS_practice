# 5. Separate `if` vs `if...else if`

This is a very common output-based interview question.

### Example A: Separate `if` statements

```
let x = 15;

if (x > 10) {
    console.log("A");
}

if (x > 20) {
    console.log("B");
} else {
    console.log("C");
}
```

Output:

```
A
C
```

Both `if` statements are evaluated independently.

The `else` belongs to the second `if`.

### Example B: `if...else if`

```
let x = 15;

if (x > 10) {
    console.log("A");
} else if (x > 20) {
    console.log("B");
} else {
    console.log("C");
}
```

Output:

```
A
```

Only the first matching block executes.

Quick trick: Separate `if` statements can print multiple outputs. An `if...else if...else` chain executes at most one branch.
