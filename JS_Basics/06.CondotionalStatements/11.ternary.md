# 12. Ternary Operator `? :`

Ternary is a short form of `if...else`.

### Syntax

```
condition ? valueIfTrue : valueIfFalse;
```

Example:

```
let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);
```

Output:

```
Adult
```

### How to read it

`age >= 18 ? "Adult" : "Minor"`

Read it as:

> If age is greater than or equal to 18, return "Adult", otherwise return "Minor".

### Example: Even or Odd

```
let num = 7;

let result = num % 2 === 0 ? "Even" : "Odd";

console.log(result);
```

Output:

```
Odd
```

### Nested ternary

```
let marks = 85;

let grade = marks >= 90
    ? "A"
    : marks >= 80
        ? "B"
        : marks >= 70
            ? "C"
            : "Fail";

console.log(grade);
```

Output:

```
B
```

### Trick: Ternary is an expression

It can return a value.

```
let a = 10;
let b = 20;

let max = a > b ? a : b;

console.log(max); // 20
```

### When NOT to use ternary

Avoid complex nested ternaries. They are difficult to read and debug.

Use `if...else` when the logic has multiple steps.
