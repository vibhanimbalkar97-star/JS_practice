# 14. Operator Precedence in Conditions

Operator precedence tells JavaScript which operation happens first.

\| Priority | Operators |\
\|---|---|\
\| Highest | `()` |\
\| Next | `!` |\
\| Next | `*`, `/`, `%` |\
\| Next | `+`, `-` |\
\| Next | `<`, `>`, `<=`, `>=` |\
\| Next | `==`, `===`, `!=`, `!==` |\
\| Next | `&&` |\
\| Next | `||` |\
\| Next | `??` |\
\| Lower | `?:` |

Note: Some operators share precedence levels, and assignment has lower precedence than these conditional operators. Parentheses are the safest way to make complex expressions clear.

### Example

```
console.log(true || false && false);
```

Output:

```
true
```

Why?

`&&` executes before `||`.

```
true || (false && false)
```

```
true || false
```

```
true
```

### Trick

```
let x = 5;

console.log(x > 2 && x < 10 || x === 20);
```

Output:

```
true
```

Evaluate:

```
(x > 2 && x < 10) || x === 20
```

The first part is true, so the whole expression is true.
