# JavaScript Conditional Statements – Complete Beginner Notes

JavaScript conditional statements help us make decisions in a program.

For example:

- If a user is logged in → show dashboard.
- If marks are above 35 → pass.
- If a number is even → print Even.
- If a user is an adult → allow access.

The most important thing for interviews is understanding how JavaScript evaluates conditions, which block executes, and why.

We'll cover all major rules, examples, tricky cases, and interview tips.

# 1. Types of Conditional Statements

\| Concept                         | Purpose |
\| `if`                            | Execute code when condition is true |\
\| `if...else`                     | Choose between two options |\
\| `if...else if...else`           | Choose among multiple conditions |\
\| Nested `if`                     | Put an `if` inside another `if` |\
\| Ternary operator `? :`          | Write a short conditional expression |\
\| `switch`                        | Compare one value against multiple cases |\
\| Short-circuit `&&`              | Execute/check next part only when previous is truthy |\
\| Short-circuit `||`              | Execute/check next part only when previous is falsy |\
\| Nullish coalescing `??`         | Use fallback only for `null` or `undefined` |
