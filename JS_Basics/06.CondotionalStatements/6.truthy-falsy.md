# 7. Truthy and Falsy Values

JavaScript does not require every condition to be explicitly `true` or `false`.

It converts the value to a Boolean internally.

Example:

```
if (10) {
    console.log("Truthy");
}
```

Output:

```
Truthy
```

## Important Falsy Values

Memorize these values:

| Value       | Boolean conversion |
| ----------- | ------------------ |
| `false`     | `false`            |
| `0`         | `false`            |
| `-0`        | `false`            |
| `0n`        | `false`            |
| `""`        | `false`            |
| `null`      | `false`            |
| `undefined` | `false`            |
| `NaN`       | `false`            |

Everything else is truthy, including empty arrays and empty objects.

### Important Interview Trick

```
console.log(Boolean([]));
console.log(Boolean({}));
console.log(Boolean("0"));
console.log(Boolean("false"));
```

Output:

```
true
true
true
true
```

Why?

- is an object → truthy.
- `{}` is an object → truthy.
- `"0"` is a non-empty string → truthy.
- `"false"` is a non-empty string → truthy.

JavaScript does not check the meaning of the string. It checks whether the string is empty.

### Truthy vs Falsy Quick Table

| Value     | Truthy/Falsy |
| --------- | ------------ |
| `0`       | Falsy        |
| `"0"`     | Truthy       |
| `false`   | Falsy        |
| `"false"` | Truthy       |
| `[]`      | Truthy       |
| `""`      | Falsy        |
| `{}`      | Truthy       |
| `null`    | Falsy        |
| `NaN`     | Falsy        |

### Trick: Empty array is not empty in a condition

```
let arr = [];

if (arr) {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
A
```

To check whether the array has elements:

```
if (arr.length > 0) {
    console.log("Not empty");
} else {
    console.log("Empty");
}
```
