# 15. Important Interview Tricks and Tricky Examples

These are some common JavaScript output questions.

## Trick 1: `if ([])`

```
if ([]) {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
A
```

Empty array is truthy.

## Trick 2: `if ("false")`

```
if ("false") {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
A
```

The string is non-empty.

## Trick 3: `if (NaN)`

```
if (NaN) {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
B
```

`NaN` is falsy.

## Trick 4: `if (new Boolean(false))`

```
let value = new Boolean(false);

if (value) {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
A
```

Why?

`new Boolean(false)` creates an object.

All objects are truthy, even if they wrap `false`.

Avoid using `new Boolean()`.

## Trick 5: Comparison chaining

```
console.log(5 < 10 < 15);
```

Output:

```
true
```

Why?

JavaScript evaluates from left to right:

```
5 < 10      // true
true < 15   // true
```

When a Boolean is compared numerically, `true` converts to `1`.

### Very tricky example

```
console.log(15 < 10 < 5);
```

Output:

```
true
```

Why?

```
15 < 10       // false
false < 5     // 0 < 5 → true
```

Interview trick: Do not write chained comparisons like Python.

Incorrect for a range:

```
if (1 < x < 10) {
    console.log("Valid");
}
```

Correct:

```
if (x > 1 && x < 10) {
    console.log("Valid");
}
```

## Trick 6: Negation with equality

```
let x = 5;

console.log(!x === 5);
```

Output:

```
false
```

Why?

```
!5          // false
false === 5 // false
```

The expression is evaluated as:

```
(!x) === 5
```

## Trick 7: `&&` and `||` return values

```
console.log(5 && 0 || 10);
```

Output:

```
10
```

Step-by-step:

```
5 && 0  // 0
0 || 10 // 10
```

## Trick 8: `null` and `undefined`

```
console.log(null == undefined);
console.log(null === undefined);
```

Output:

```
true
false
```

`==` allows special type conversion here.

`===` checks the type also.

## Trick 9: `if (0 == false)`

```
if (0 == false) {
    console.log("A");
}
```

Output:

```
A
```

Because loose equality converts the values.

But:

```
if (0 === false) {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
B
```

## Trick 10: `typeof NaN`

```
console.log(typeof NaN);
```

Output:

```
number
```

Even though `NaN` means "Not a Number", its type is `number`.

```
if (NaN) {
    console.log("A");
} else {
    console.log("B");
}
```

Output:

```
B
```

# 16. Conditional Statements with User Input

In browser JavaScript, `prompt()` returns a string (or `null` if canceled).

Example:

```
let age = prompt("Enter your age");

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
```

This works because `>=` performs numeric conversion when comparing a string with a number.

However, it is better to convert explicitly:

```
let age = Number(prompt("Enter your age"));

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
```

### Trick: Empty string conversion

```
console.log(Number(""));    // 0
console.log(Number("   ")); // 0
console.log(Number("abc")); // NaN
```

So if the user enters nothing:

```
let age = Number("");

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
```

Output:

```
Minor
```

For real applications, validate the input before using it.

# 17. Common Mistakes Beginners Make

\| Mistake | Incorrect | Correct |\
\|---|---|---|\
\| Assignment instead of comparison | `if (x = 5)` | `if (x === 5)` |\
\| Using `&&` for range incorrectly | `x < 1 && x > 10` | `x < 1 || x > 10` |\
\| Assuming empty array is falsy | `if ([])` | `if (arr.length === 0)` to check emptiness |\
\| Using `==` unnecessarily | `x == 10` | `x === 10` |\
\| Forgetting `break` in switch | Cases fall through | Add `break` when needed |\
\| Wrong condition order | Lowest threshold first | Highest threshold first |\
\| Confusing `!x` with `x !== 0` | `if (!x)` | Use the expression matching the actual requirement |\
\| Using `||` for valid zero | `value || 10` | `value ?? 10` when only nullish values need fallback |\
\| Chained comparison | `1 < x < 10` | `x > 1 && x < 10` |

# 18. Problem-Solving Tricks for Interview Questions

Whenever you solve a conditional question, follow these steps:

## 5-Step Approach

1. Identify the condition

   What are you checking? Equality, range, truthiness, or multiple conditions?
2. Convert values mentally

   For example, `""` → falsy, `"0"` → truthy, `0` → falsy.
3. Check the structure

   Separate `if` statements or an `if...else if` chain?
4. Check operator precedence

   `!` before `&&`, and `&&` before `||`.
5. Dry run line by line

   Don't jump to the output. Evaluate every expression in order.

## Example: Find the largest of three numbers

```
let a = 10;
let b = 20;
let c = 15;

if (a >= b && a >= c) {
    console.log("A is largest");
} else if (b >= a && b >= c) {
    console.log("B is largest");
} else {
    console.log("C is largest");
}
```

Output:

```
B is largest
```

## Example: Check whether a number is in a range

```
let num = 7;

if (num >= 1 && num <= 10) {
    console.log("Valid");
} else {
    console.log("Invalid");
}
```

Output:

```
Valid
```

## Example: Check a login condition

```
let isLoggedIn = true;
let isAdmin = false;

if (isLoggedIn && isAdmin) {
    console.log("Admin dashboard");
} else if (isLoggedIn) {
    console.log("User dashboard");
} else {
    console.log("Please login");
}
```

Output:

```
User dashboard
```
