# 2. Creating Strings

JavaScript provides three ways to create strings.

## 2.1 Single quotes

```
let a = 'Hello';
```

## 2.2 Double quotes

```
let b = "Hello";
```

## 2.3 Backticks — Template literals

```
let c = `Hello`;
```

All three create strings.

| Syntax        | Example       | Use                             |
| ------------- | ------------- | ------------------------------- |
| Single quotes | `'Hello'`     | Normal strings                  |
| Double quotes | `"Hello"`     | Normal strings                  |
| Backticks     | `` `Hello` `` | Variables and multiline strings |

### Rule: Quotes must match

```
let a = "Hello"; // Correct
let b = 'Hello'; // Correct
```

```
let c = "Hello'; // SyntaxError
```

### Trick: Quotes inside strings

```
let a = "It's JavaScript";
let b = 'He said "Hello"';
```

Output:

```
It's JavaScript
He said "Hello"
```

If the inner and outer quotes are the same, use an escape character:

```
let text = 'It\'s JavaScript';

console.log(text);
// It's JavaScript
```
