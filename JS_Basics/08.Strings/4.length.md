# 4. String Length

The `length` property returns the number of UTF-16 code units in a string.

```
let text = "Hello";

console.log(text.length); // 5
```

### Rule: Spaces are counted

```
let text = "Hi Vibha";

console.log(text.length); // 8
```

Count:

`H i _ V i b h a` = 8

### Empty string

```
let text = "";

console.log(text.length); // 0
```

### Important interview trick

```
let text = "Hello";

console.log(text.length); // 5
console.log(text.length - 1); // 4
```

Last index = `length - 1`

Last character:

```
console.log(text[text.length - 1]); // o
```

Last character using `at()`:

```
console.log(text.at(-1)); // o
```

### Unicode trick

```
console.log("😀".length); // 2
```

Why?

Some Unicode characters use two UTF-16 code units. So `length` does not always equal the number of visible characters.

For counting Unicode code points:

```
console.log([... "😀"].length); // 1
```

For counting grapheme clusters (visible characters, including some combined emoji), use `Intl.Segmenter`.
