# 8. Escape Characters

Escape characters are used to include special characters inside strings.

| Escape | Meaning         | Example            |
| ------ | --------------- | ------------------ |
| `\n`   | New line        | `"Hello\nWorld"`   |
| `\t`   | Tab             | `"Hello\tWorld"`   |
| `\'`   | Single quote    | `'It\'s OK'`       |
| `\"`   | Double quote    | `"He said \"Hi\""` |
| `\\`   | Backslash       | `"C:\\Users"`      |
| `\r`   | Carriage return | `"\r"`             |
| `\b`   | Backspace       | `"\b"`             |

Example:

```
console.log("Hello\nWorld");
```

Output:

```
Hello
World
```

### Trick

```
console.log("Hello\\nWorld");
```

Output:

```
Hello\nWorld
```

Why?

`\\` produces a literal backslash. The `n` is then ordinary text.
