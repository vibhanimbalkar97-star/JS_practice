# 6. String Concatenation

Concatenation means joining strings.

## Using `+`

```
let first = "Hello";
let second = "World";

console.log(first + second);
// HelloWorld
```

Add a space:

```
console.log(first + " " + second);
// Hello World
```

## Using `+=`

```
let text = "Hello";

text += " World";

console.log(text); // Hello World
```

## Using `concat()`

```
let a = "Hello";
let b = "World";

console.log(a.concat(" ", b));
// Hello World
```

### Interview trick: String + Number

```
console.log("10" + 5); // "105"
console.log(10 + "5"); // "105"
console.log("10" + 5 + 2); // "1052"
console.log(10 + 5 + "2"); // "152"
```

Why?

The `+` operator performs either numeric addition or string concatenation.

When a string is involved, the operands are converted to strings in these examples.

Trick: Read the expression from left to right.

# 7. Template Literals

Template literals use backticks.

They support:

1. Variable interpolation
2. Expressions
3. Multiline strings

## 7.1 Variable interpolation

```
let name = "Vibha";
let age = 30;

console.log(`My name is ${name} and I am ${age} years old.`);
```

Output:

```
My name is Vibha and I am 30 years old.
```

### Rule

`${}` works inside backticks, not ordinary quotes.

```
console.log("Hello ${name}"); // Hello ${name}
console.log(`Hello ${name}`); // Hello Vibha
```

## 7.2 Expressions

```
let a = 10;
let b = 20;

console.log(`Total = ${a + b}`);
// Total = 30
```

```
console.log(`Result = ${5 > 3}`);
// Result = true
```

## 7.3 Multiline strings

```
let text = `Hello
World`;

console.log(text);
```

Output:

```
Hello
World
```
