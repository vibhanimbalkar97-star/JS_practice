# 3. String Indexing

Each character in a string has an index.

JavaScript indexing starts from 0.

```
let text = "HELLO";
```

| Character                  | H  | E  | L  | L  | O  |
| -------------------------- | -- | -- | -- | -- | -- |
| Index                      | 0  | 1  | 2  | 3  | 4  |
| Negative position from end | -5 | -4 | -3 | -2 | -1 |

## Accessing characters

```
let text = "HELLO";

console.log(text[0]); // H
console.log(text[1]); // E
console.log(text[4]); // O
console.log(text[5]); // undefined
```

### Rule: Out-of-range index

```
let text = "Hello";

console.log(text[10]); // undefined
```

No error occurs. The character simply does not exist.

## Using `at()`

```
let text = "HELLO";

console.log(text.at(0));  // H
console.log(text.at(-1)); // O
console.log(text.at(-2)); // L
```

### Important difference

```
let text = "HELLO";

console.log(text[-1]);    // undefined
console.log(text.at(-1)); // O
```

Interview trick: Negative indexing works with `at()`, not ordinary bracket indexing.
