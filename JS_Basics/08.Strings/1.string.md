# 1. What is a String?

A string is a sequence of characters used to store text.

```
let name = "Vibha";
let message = "Hello World";
let city = "Pune";
```

A string can contain:

- Letters: `"JavaScript"`
- Numbers as text: `"123"`
- Symbols: `"@#$"`
- Spaces: `"Hello World"`
- Empty text: `""`

```
let a = "123";
let b = 123;

console.log(typeof a); // string
console.log(typeof b); // number
```

Interview rule: Numbers inside quotes are strings, not numbers.
