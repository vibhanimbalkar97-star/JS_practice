## 9.3 Searching Methods

These methods help you find characters or words inside a string.

| Method          | Purpose                   | Returns     |
| --------------- | ------------------------- | ----------- |
| `indexOf()`     | First matching position   | Number      |
| `lastIndexOf()` | Last matching position    | Number      |
| `includes()`    | Checks if present         | Boolean     |
| `startsWith()`  | Checks beginning          | Boolean     |
| `endsWith()`    | Checks ending             | Boolean     |
| `search()`      | Finds a match using regex | Index or -1 |

### `indexOf()`

Returns the first index of the specified value.

```
let text = "JavaScript";

console.log(text.indexOf("a")); // 1
console.log(text.indexOf("S")); // 4
console.log(text.indexOf("z")); // -1
```

If not found, returns `-1`.

### Rule: Repeated characters

```
let text = "banana";

console.log(text.indexOf("a")); // 1
```

It returns the first matching index.

### `lastIndexOf()`

Returns the last matching position.

```
let text = "banana";

console.log(text.lastIndexOf("a")); // 5
console.log(text.lastIndexOf("n")); // 4
```

### `includes()`

Checks whether the string contains a value.

```
let text = "JavaScript";

console.log(text.includes("Script")); // true
console.log(text.includes("script")); // false
```

Case-sensitive!

### `startsWith()`

```
let text = "JavaScript";

console.log(text.startsWith("Java")); // true
console.log(text.startsWith("Script")); // false
```

### `endsWith()`

```
let text = "JavaScript";

console.log(text.endsWith("Script")); // true
console.log(text.endsWith("Java")); // false
```

### Search methods with position

```
let text = "banana";

console.log(text.indexOf("a", 2)); // 3
console.log(text.includes("a", 4)); // true
```

The second argument specifies where to begin searching.

### `search()`

```
let text = "Hello123";

console.log(text.search(/[0-9]/)); // 5
```

`/[0-9]/` searches for a digit.

### Critical interview trick: `indexOf()` and `includes()`

```
let text = "Hello";

console.log(text.indexOf("z")); // -1
console.log(text.includes("z")); // false
```

Never confuse `-1` with `false`.
