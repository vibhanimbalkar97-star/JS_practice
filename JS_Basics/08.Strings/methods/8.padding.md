## 9.8 Padding Methods

Padding adds characters to the beginning or end of a string until it reaches a specified length.

### `padStart()`

```
let text = "5";

console.log(text.padStart(3, "0"));
// 005
```

### `padEnd()`

```
let text = "5";

console.log(text.padEnd(3, "0"));
// 500
```

### Rule

The first argument is the target length.

```
console.log("Hi".padStart(5, "*"));
// ***Hi
```

### Tricky example

```
console.log("Hello".padStart(3, "*"));
// Hello
```

Why?

The string already has a length of 5. Padding does not shorten strings.

### Use case: Format numbers as text

```
let number = "7";

console.log(number.padStart(2, "0"));
// 07
```
