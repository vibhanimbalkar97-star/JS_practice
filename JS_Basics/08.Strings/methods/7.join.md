## 9.7 Joining Strings — `concat()` and `join()`

### `concat()`

Joins strings.

```
let a = "Hello";
let b = "World";

console.log(a.concat(" ", b));
// Hello World
```

### `join()`

Joins array elements into a string.

```
let arr = ["JavaScript", "Python", "React"];

console.log(arr.join(", "));
// JavaScript, Python, React
```

### Important difference

```
let text = "Hello";

console.log(text.concat(" World"));
// Hello World
```

```
let arr = ["Hello", "World"];

console.log(arr.join(" "));
// Hello World
```

`concat()` is a string method and can also be used with arrays. `join()` is an array method.
