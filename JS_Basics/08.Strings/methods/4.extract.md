## 9.4 Extracting Parts of a String

Three important methods:

- `slice()`
- `substring()`
- `substr()` — deprecated; avoid using it in new code.

### `slice(start, end)`

Extracts a portion of a string.

```
let text = "JavaScript";

console.log(text.slice(0, 4)); // Java
console.log(text.slice(4, 10)); // Script
```

### Most important rule

The `end` index is excluded.

```
let text = "Hello";

console.log(text.slice(1, 4));
// ell
```

Indexes:

| Character | H | e | l | l | o |
| --------- | - | - | - | - | - |
| Index     | 0 | 1 | 2 | 3 | 4 |

`slice(1, 4)` includes indexes 1, 2, 3.

### Negative indexes with `slice()`

```
let text = "JavaScript";

console.log(text.slice(-6)); // Script
console.log(text.slice(-3)); // ipt
console.log(text.slice(-6, -3)); // Scr
```

### Omitting the end

```
let text = "JavaScript";

console.log(text.slice(4));
// Script
```

It extracts from index 4 to the end.

### `substring(start, end)`

```
let text = "JavaScript";

console.log(text.substring(0, 4));
// Java
```

The `end` is excluded, just like `slice()`.

### `slice()` vs `substring()`

| Rule                   | `slice()`            | `substring()`   |
| ---------------------- | -------------------- | --------------- |
| Negative start         | Counts from end      | Converts to 0   |
| Negative end           | Counts from end      | Converts to 0   |
| Start greater than end | Returns empty string | Swaps arguments |
| End excluded           | Yes                  | Yes             |

### Tricky example 1

```
let text = "JavaScript";

console.log(text.slice(-4)); 
// ript

console.log(text.substring(-4));
// JavaScript
```

Why?

- `slice(-4)` means start four positions from the end.
- `substring(-4)` treats `-4` as `0`.

### Tricky example 2

```
let text = "Hello";

console.log(text.slice(4, 1)); 
// ""

console.log(text.substring(4, 1));
// ell
```

Why?

- `slice()` does not swap indexes.
- `substring()` swaps them.

### `substr()`

```
let text = "JavaScript";

console.log(text.substr(4, 3));
// Scr
```

Its second argument means length, not end index.

`substr()` is deprecated, so prefer `slice()`.
