# 9. Important String Methods — Complete Notes

Remember:

- String methods return values.
- Most methods do not modify the original string.
- String methods are case-sensitive unless the method specifically handles case.

We will divide methods into categories.

## 9.1 Case Conversion Methods

### `toUpperCase()`

Converts all letters to uppercase.

```
let text = "JavaScript";

console.log(text.toUpperCase());
// JAVASCRIPT
```

### `toLowerCase()`

Converts all letters to lowercase.

```
let text = "JavaScript";

console.log(text.toLowerCase());
// javascript
```

### `toLocaleUpperCase()` and `toLocaleLowerCase()`

These methods perform case conversion according to locale-specific rules.

```
console.log("hello".toLocaleUpperCase());
// HELLO
```

For normal interview questions, use `toUpperCase()` and `toLowerCase()`.

### Trick: Case-sensitive comparison

```
console.log("hello" === "HELLO"); // false
```

To compare without considering case:

```
let a = "Hello";
let b = "HELLO";

console.log(a.toLowerCase() === b.toLowerCase());
// true
```
