## 9.5 Replacing Text

### `replace()`

Replaces the first matching occurrence.

```
let text = "Hello Hello";

console.log(text.replace("Hello", "Hi"));
// Hi Hello
```

### Rule: Only first occurrence

```
let text = "banana";

console.log(text.replace("a", "o"));
// bonana
```

### `replaceAll()`

Replaces all occurrences.

```
let text = "banana";

console.log(text.replaceAll("a", "o"));
// bonono
```

### Difference

| Method         | What it replaces                     |
| -------------- | ------------------------------------ |
| `replace()`    | First occurrence for a string search |
| `replaceAll()` | All occurrences for a string search  |

### Using regular expressions

```
let text = "banana";

console.log(text.replace(/a/g, "o"));
// bonono
```

Here:

- `/a/` = search for `a`
- `g` = global flag, all occurrences

### Interview trick

```
let text = "Hello Hello";

console.log(text.replace(/Hello/, "Hi"));
// Hi Hello

console.log(text.replace(/Hello/g, "Hi"));
// Hi Hi
```
