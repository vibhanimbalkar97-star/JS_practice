# 5. Strings Are Immutable

Immutable means a value cannot be changed after it is created.

```
let text = "Hello";

text[0] = "Y";

console.log(text); // Hello
```

Why?

JavaScript strings are immutable. You cannot change an individual character in an existing string.

### Correct way: Create a new string

```
let text = "Hello";

text = "Y" + text.slice(1);

console.log(text); // Yello
```

Here:

1. `"Y"` is added.
2. `text.slice(1)` gives `"ello"`.
3. A new string `"Yello"` is created.
4. The variable `text` now refers to the new string.

### Important

```
let a = "Hello";

a.toUpperCase();

console.log(a); // Hello
```

Why?

`toUpperCase()` returns a new string. It does not modify the original.

Correct:

```
a = a.toUpperCase();

console.log(a); // HELLO
```
