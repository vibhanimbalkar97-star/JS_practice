# 3. `while` Loop

A `while` loop is useful when you don't know exactly how many times the loop should run.

## Syntax

```
while (condition) {
  // code
}
```

### Example

```
let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}
```

Output:

```
1
2
3
4
5
```

### Important rules

Rule 1: The condition is checked before the body.

```
let i = 10;

while (i < 5) {
  console.log(i);
}
```

Output: No output.

Rule 2: Always update the variable when needed.

```
let i = 1;

while (i <= 3) {
  console.log(i);
}
```

This is an infinite loop because `i` never changes.

Rule 3: The condition can become false inside the loop.

```
let i = 1;

while (i <= 5) {
  console.log(i);
  i += 2;
}
```

Output:

```
1
3
5
```
