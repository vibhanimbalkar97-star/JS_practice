# JavaScript Nested Loop – हिंदी में आसान Explanation

Nested loop का मतलब है एक loop के अंदर दूसरा loop।

इसे ऐसे समझो:

मान लो तुम्हारे पास 2 students हैं और हर student को 3 questions solve करने हैं।

- Student 1 → Question 1, 2, 3
- Student 2 → Question 1, 2, 3

यहाँ students वाला loop Outer Loop है और questions वाला loop Inner Loop है।

सबसे जरूरी बात:

> Outer loop की एक iteration के लिए Inner loop पूरा चलता है। उसके बाद ही Outer loop की अगली iteration शुरू होती है।

## 1. सबसे आसान Example

```
for (let i = 1; i <= 2; i++) {
  for (let j = 1; j <= 3; j++) {
    console.log(i, j);
  }
}
```

Output:

```
1 1
1 2
1 3
2 1
2 2
2 3
```

पहले यह समझते हैं कि `i` और `j` क्या हैं।

- `i` = Outer loop का variable
- `j` = Inner loop का variable

यहाँ `i` 2 बार चलेगा और `j` हर बार 3 बार चलेगा।

इसलिए total output = 2 × 3 = 6 times.

## 2. Code को Step-by-Step कैसे Run करते हैं?

इस code को ध्यान से देखो:

```
for (let i = 1; i <= 2; i++) {
  for (let j = 1; j <= 3; j++) {
    console.log(i, j);
  }
}
```

### Step 1: Outer loop शुरू होता है

```
let i = 1;
```

Condition check:

```
i <= 2
1 <= 2 // true
```

Outer loop अंदर enter करता है।

### Step 2: Inner loop शुरू होता है

```
let j = 1;
```

Condition:

```
j <= 3
1 <= 3 // true
```

अब:

```
console.log(i, j);
```

Output:

```
1 1
```

### Step 3: Inner loop का update

```
j++;
```

अब `j = 2` हो गया।

Condition:

```
2 <= 3 // true
```

Output:

```
1 2
```

फिर `j++` → `j = 3`

Condition:

```
3 <= 3 // true
```

Output:

```
1 3
```

अब `j++` → `j = 4`

Condition:

```
4 <= 3 // false
```

Inner loop खत्म!

ध्यान दो: अभी Outer loop का `i` सिर्फ 1 है। अब Outer loop आगे बढ़ेगा।

### Step 4: Outer loop का update

```
i++;
```

अब `i = 2`

Condition:

```
2 <= 2 // true
```

Outer loop की दूसरी iteration शुरू हुई।

अब Inner loop फिर से initialize होगा:

```
let j = 1;
```

ध्यान दो! `j` फिर से 1 हो गया।

फिर Inner loop चलेगा:

```
2 1
2 2
2 3
```

इसके बाद `j = 4`, condition false।

फिर `i++` → `i = 3`

Outer condition:

```
3 <= 2 // false
```

अब पूरा Nested Loop खत्म।

## 4. सबसे आसान Trick – Inner Loop कितनी बार चलेगा?

यह example देखो:

```
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= i; j++) {
    console.log(i, j);
  }
}
```

यहाँ inner loop की condition `j <= i` है।

मतलब `j` की limit, `i` पर depend करती है।

### Dry Run

| Outer `i` | Inner `j` values | Output count |
| --------- | ---------------- | ------------ |
| 1         | 1                | 1            |
| 2         | 1, 2             | 2            |
| 3         | 1, 2, 3          | 3            |

Output:

```
1 1
2 1
2 2
3 1
3 2
3 3
```

Total output:

\\[ 1+2+3=6 \\]

याद रखो: जब inner loop की limit `i` है, तो हर outer iteration में inner loop की repetitions बदल सकती हैं।

## 5. Nested Loop से Star Pattern कैसे बनता है?

यह beginner interviews में बहुत पूछा जाता है।

```
for (let i = 1; i <= 3; i++) {
  let row = "";

  for (let j = 1; j <= 3; j++) {
    row += "*";
  }

  console.log(row);
}
```

Output:

```
***
***
***
```

### Hindi में समझो

- Outer loop बताता है कितनी rows बनेंगी।
- Inner loop बताता है हर row में कितने stars होंगे।
- `row += "*"` एक star जोड़ता है।
- Inner loop पूरा होने के बाद `console.log(row)` एक पूरी row print करता है।

### अब बदलकर देखो

```
for (let i = 1; i <= 3; i++) {
  let row = "";

  for (let j = 1; j <= i; j++) {
    row += "*";
  }

  console.log(row);
}
```

Output:

```
*
**
***
```

यहाँ `j <= i` है, इसलिए हर नई row में एक extra star आता है।

## 6. Nested Loop के Questions Solve करने का Formula

जब भी nested loop का कोई question आए, ये 5 steps follow करो।

1. Outer loop देखो – `i` कहाँ से शुरू है और कहाँ तक जाएगा?
2. Inner loop देखो – `j` कहाँ से शुरू है और उसकी condition क्या है?
3. Inner loop को पूरा चलाओ – एक outer iteration में सभी inner iterations complete करो।
4. Inner variable reset करो – Outer की अगली iteration में `j` फिर initialize होता है।
5. Output क्रम से लिखो – हर `console.log()` को उसी समय लिखो जब code execute होता है।

### एक बहुत important trick

```
for (let i = 1; i <= 3; i++) {
  console.log("A");

  for (let j = 1; j <= 2; j++) {
    console.log("B");
  }

  console.log("C");
}
```

पहले खुद सोचो।

Output:

```
A
B
B
C
A
B
B
C
A
B
B
C
```

क्यों?

हर Outer iteration में:

```
A → B → B → C
```

यह पूरा sequence 3 बार repeat होता है।
