# 10. Labeled `break` and `continue`

Labels allow you to control an outer loop from inside a nested loop.

### Labeled break

```
outer:
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; j++) {
    if (i === 2 && j === 2) {
      break outer;
    }

    console.log(i, j);
  }
}
```

Output:

```
1 1
1 2
1 3
2 1
```

`break outer` stops both loops.

### Labeled continue

```
outer:
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 2; j++) {
    if (j === 2) {
      continue outer;
    }

    console.log(i, j);
  }
}
```

Output:

```
1 1
2 1
3 1
```

`continue outer` skips to the next outer iteration.
