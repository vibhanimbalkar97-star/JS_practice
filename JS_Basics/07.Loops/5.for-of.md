# 5. `for...of` Loop

Used to iterate over the values of iterable objects like arrays, strings, maps, and sets.

## Syntax

```
for (let value of iterable) {
  // code
}
```

### Example: Array

```
let fruits = ["Apple", "Mango", "Banana"];

for (let fruit of fruits) {
  console.log(fruit);
}
```

Output:

```
Apple
Mango
Banana
```

### Example: String

```
let name = "JS";

for (let char of name) {
  console.log(char);
}
```

Output:

```
J
S
```

### Example: Sum of array values

```
let numbers = [10, 20, 30];
let sum = 0;

for (let num of numbers) {
  sum += num;
}

console.log(sum);
```

Output:

```
60
```

### Tricky point

`for...of` gives values, not indexes.

```
let arr = ["A", "B", "C"];

for (let value of arr) {
  console.log(value);
}
```

Output:

```
A
B
C
```

If you need indexes:

```
for (let [index, value] of arr.entries()) {
  console.log(index, value);
}
```

Output:

```
0 A
1 B
2 C
```
