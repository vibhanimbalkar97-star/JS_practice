# 6. `for...in` Loop

Used to iterate over the enumerable property keys of an object.

## Syntax

```
for (let key in object) {
  // code
}
```

### Example: Object

```
let student = {
  name: "Amit",
  age: 22,
  city: "Pune"
};

for (let key in student) {
  console.log(key);
}
```

Output:

```
name
age
city
```

### Get both key and value

```
for (let key in student) {
  console.log(key, student[key]);
}
```

Output:

```
name Amit
age 22
city Pune
```

### Tricky: `for...in` with an array

```
let arr = ["A", "B", "C"];

for (let index in arr) {
  console.log(index);
}
```

Output:

```
0
1
2
```

Why? `for...in` gives keys. Array indexes are keys.

### Important interview rule

- Use `for...of` for array values.
- Use `for...in` for object keys.
- Avoid using `for...in` for arrays when you need predictable array iteration.
