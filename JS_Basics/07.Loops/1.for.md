# 2. The `for` Loop

## Syntax

```
for (initialization; condition; update) {
  // code to execute
}
```

### Three important parts

| Part           | Meaning                      | Example     |
| -------------- | ---------------------------- | ----------- |
| Initialization | Starting point               | `let i = 1` |
| Condition      | Check before every iteration | `i <= 5`    |
| Update         | Change the value             | `i++`       |

### Example

```
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

Output:

```
1
2
3
4
5
```

### Rule 1: Condition is checked before execution

```
for (let i = 10; i < 5; i++) {
  console.log(i);
}
```

Output:

```
// No output
```

Why? The condition is false at the beginning.

### Rule 2: Initialization happens only once

```
for (let i = 1; i <= 3; i++) {
  console.log(i);
}
```

`let i = 1` is not repeated every iteration.

### Rule 3: Update happens after the body

```
for (let i = 1; i <= 3; i++) {
  console.log(i);
}
```

Execution order:

```
i = 1 → condition → body → i++
i = 2 → condition → body → i++
i = 3 → condition → body → i++
i = 4 → condition false → stop
```

## Tricky `for` loop examples

### Example 1: Increment by 2

```
for (let i = 1; i <= 10; i += 2) {
  console.log(i);
}
```

Output:

```
1
3
5
7
9
```

### Example 2: Decrement

```
for (let i = 5; i >= 1; i--) {
  console.log(i);
}
```

Output:

```
5
4
3
2
1
```

### Example 3: Empty sections

```
let i = 1;

for (; i <= 3;) {
  console.log(i);
  i++;
}
```

Output:

```
1
2
3
```

The three sections are optional, but the semicolons remain.

### Example 4: Multiple variables

```
for (let i = 1, j = 5; i <= 3; i++, j--) {
  console.log(i, j);
}
```

Output:

```
1 5
2 4
3 3
```

Let's understand this code in simple Hindi + English, step by step.

## 1. Code

```
for (let i = 1, j = 5; i <= 3; i++, j--) {
  console.log(i, j);
}
```

Here, we are using two variables in one `for` loop.

- `i` starts from 1 and increases (`i++`).
- `j` starts from 5 and decreases (`j--`).
- Loop continues while `i <= 3`.

## 2. Understand the 3 parts

```
for (let i = 1, j = 5; i <= 3; i++, j--)
```

| Part               | Meaning                    |
| ------------------ | -------------------------- |
| `let i = 1, j = 5` | Start both variables       |
| `i <= 3`           | Check only `i` condition   |
| `i++, j--`         | Increase `i`, decrease `j` |

Important: Both `i++` and `j--` happen after the loop body executes.

## 3. Step-by-step execution

Step 1

Initialization

```
i = 1
j = 5
```

Check condition:

`i <= 3` → `1 <= 3` → `true`

Execute:

```
console.log(i, j);
```

Output: `1 5`

Step 2

Update both variables

```
i++  // i = 2
j--  // j = 4
```

Check condition:

`2 <= 3` → `true`

Output: `2 4`

Step 3

Update both variables again

```
i++  // i = 3
j--  // j = 3
```

Check condition:

`3 <= 3` → `true`

Output: `3 3`

Step 4

Update both variables

```
i++  // i = 4
j--  // j = 2
```

Check condition:

`4 <= 3` → `false`

Loop stops. No output for this step.

## 4. Final Output

```
1 5
2 4
3 3
```

## 5. Dry Run Table

| Iteration | `i` | `j` | Condition `i <= 3` | Output |
| --------- | --- | --- | ------------------ | ------ |
| 1         | 1   | 5   | True               | `1 5`  |
| 2         | 2   | 4   | True               | `2 4`  |
| 3         | 3   | 3   | True               | `3 3`  |
| 4         | 4   | 2   | False              | Stop   |

## 6. Easy trick to remember

Think of two people:

- Person `i` starts at 1 and walks forward.
- Person `j` starts at 5 and walks backward.
- Every round, both move together.

```
i:  1 → 2 → 3 → 4
j:  5 → 4 → 3 → 2
```

But printing happens only while `i <= 3`.

### One important interview point

```
for (let i = 1, j = 5; i <= 3; i++, j--) {
```

The condition checks only `i`, not `j`.

Even though `j` is also declared in the loop, it doesn't automatically become part of the condition.

If you want, try this similar question:

```
for (let i = 2, j = 8; i <= 4; i++, j -= 2) {
  console.log(i, j);
}
```

What will be the output?

Almost! You got the `j` values correct, but the first `j` value is `8`, not `6`. 😊

Let's check:

```
for (let i = 2, j = 8; i <= 4; i++, j -= 2) {
  console.log(i, j);
}
```

| Iteration | `i` | `j` | Output |
| --------- | --- | --- | ------ |
| 1         | 2   | 8   | `2 8`  |
| 2         | 3   | 6   | `3 6`  |
| 3         | 4   | 4   | `4 4`  |
| 4         | 5   | 2   | Stop   |

Correct output:

```
2 8
3 6
4 4
```

Remember: `console.log()` executes first, then `i++` and `j -= 2` update the values.

You understood the update logic correctly—just remember the initial values!
