# 15. Looping Through Arrays and Objects

This is very important for React and MERN interviews.

## Array of objects

```
let students = [
  { name: "Amit", marks: 80 },
  { name: "Neha", marks: 90 },
  { name: "Raj", marks: 70 }
];
```

### Using `for`

```
for (let i = 0; i < students.length; i++) {
  console.log(students[i].name);
}
```

Output:

```
Amit
Neha
Raj
```

### Using `for...of`

```
for (let student of students) {
  console.log(student.name, student.marks);
}
```

Output:

```
Amit 80
Neha 90
Raj 70
```

### Using `map()`

```
let names = students.map((student) => student.name);

console.log(names);
```

Output:

```
["Amit", "Neha", "Raj"]
```

### Using `filter()`

```
let passed = students.filter((student) => student.marks >= 80);

console.log(passed);
```

Output:

```
[
  { name: "Amit", marks: 80 },
  { name: "Neha", marks: 90 }
]
```

### Tricky: Nested object

```
let users = [
  { name: "Amit", skills: ["JS", "React"] },
  { name: "Neha", skills: ["Python", "ML"] }
];

for (let user of users) {
  for (let skill of user.skills) {
    console.log(user.name, skill);
  }
}
```

Output:

```
Amit JS
Amit React
Neha Python
Neha ML
```
