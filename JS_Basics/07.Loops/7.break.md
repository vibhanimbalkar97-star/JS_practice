# 7. `break` Statement

`break` immediately stops the loop.

### Example

```
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    break;
  }

  console.log(i);
}
```

Output:

```
1
2
```

Why not 3, 4, 5?

When `i === 3`, `break` terminates the loop.

### Tricky example

```
for (let i = 1; i <= 5; i++) {
  console.log(i);

  if (i === 3) {
    break;
  }
}
```

Output:

```
1
2
3
```

Trick: The position of `break` matters. Here, 3 prints before the loop stops.
