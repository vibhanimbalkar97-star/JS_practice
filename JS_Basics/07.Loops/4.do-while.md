# 4. `do...while` Loop

The `do...while` loop executes the code at least once, even if the condition is false.

## Syntax

```
do {
  // code
} while (condition);
```

### Example

```
let i = 10;

do {
  console.log(i);
  i++;
} while (i < 5);
```

Output:

```
10
```

Why?

- The body executes first.
- Then the condition is checked.
- The condition is false, so the loop stops.

### Comparison

| `while`                                     | `do...while`                                 |
| ------------------------------------------- | -------------------------------------------- |
| Checks condition first                      | Executes body first                          |
| May execute zero times                      | Executes at least once                       |
| No semicolon after `while(condition)` block | Semicolon required after `while(condition);` |

### Interview trick

```
let x = 0;

do {
  console.log(x);
  x++;
} while (x < 0);
```

Output:

```
0
```
