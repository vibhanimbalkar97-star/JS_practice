# 7. Adding and Removing Array Elements

These four methods are extremely important for interviews.

## 7.1 push() – Add at the end

```
let arr = [10, 20, 30];

arr.push(40);

console.log(arr); // [10, 20, 30, 40]
```

Add multiple elements:

```
arr.push(50, 60);

console.log(arr); // [10, 20, 30, 40, 50, 60]
```

- Changes original array.
- Returns the new array length.

```
let result = arr.push(70);

console.log(result); // 7
```

## 7.2 pop() – Remove from the end

```
let arr = [10, 20, 30];

let result = arr.pop();

console.log(arr);    // [10, 20]
console.log(result); // 30
```

- Changes original array.
- Returns the removed element.

If array is empty:

```
let arr = [];

console.log(arr.pop()); // undefined
```

## 7.3 unshift() – Add at the beginning

```
let arr = [20, 30];

arr.unshift(10);

console.log(arr); // [10, 20, 30]
```

Add multiple elements:

```
arr.unshift(1, 5);

console.log(arr); // [1, 5, 10, 20, 30]
```

Returns the new length.

## 7.4 shift() – Remove from the beginning

```
let arr = [10, 20, 30];

let result = arr.shift();

console.log(arr);    // [20, 30]
console.log(result); // 10
```

Returns the removed element.

### Quick comparison

| Method      | Action | Position | Return value    | Changes original? |
| ----------- | ------ | -------- | --------------- | ----------------- |
| `push()`    | Add    | End      | New length      | Yes               |
| `pop()`     | Remove | End      | Removed element | Yes               |
| `unshift()` | Add    | Start    | New length      | Yes               |
| `shift()`   | Remove | Start    | Removed element | Yes               |

Interview trick: Don't confuse the return values of `push()` and `pop()`.
