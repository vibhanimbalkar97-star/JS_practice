# 6. Array length Property

`length` tells us the number of positions in the array, not necessarily the number of actual elements.

```
let arr = [10, 20, 30, 40];

console.log(arr.length); // 4
```

### Changing length

```
let arr = [10, 20, 30, 40];

arr.length = 2;

console.log(arr); // [10, 20]
```

Why?

Reducing `length` removes elements beyond the new length.

Increasing it creates empty slots:

```
let arr = [10, 20];

arr.length = 5;

console.log(arr); // [10, 20, empty × 3]
```



Important

&#x20;Increasing or decreasing array length changes the actual array.
