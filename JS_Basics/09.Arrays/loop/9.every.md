# 25. every() – Check Whether All Elements Match

Returns `true` only if every element passes the condition.

```
let numbers = [2, 4, 6, 8];

console.log(numbers.every(num => num % 2 === 0));
// true
```

Another example:

```
let numbers = [2, 4, 5, 8];

console.log(numbers.every(num => num % 2 === 0));
// false
```

Because `5` is odd.

### some() vs every()

| some()                  | every()              |
| ----------------------- | -------------------- |
| At least one must match | All must match       |
| OR-like logic           | AND-like logic       |
| Stops on first true     | Stops on first false |

Interview trick:

```
[].some(x => x > 0);  // false
[].every(x => x > 0); // true
```

Why is `every()` true for an empty array?

Because there is no element that violates the condition. This is called vacuous truth.

The phrase "violates the condition. This is called vacuous truth." in the context of JavaScript (JS) translates to:
"यह शर्त का उल्लंघन करता है। इसे 'वैक्यूअस ट्रुथ' (रिक्तिपूर्ण सत्य या स्वतः सत्य) कहा जाता है।"

सरल शब्दों में इसका मतलब (Meaning in Simple Hindi):

JavaScript में जब आप किसी खाली लिस्ट (empty array) पर कुछ जांचने वाले फंक्शन (जैसे .every()) चलाते हैं, तो शर्त का उल्लंघन करने वाला (गलत साबित करने वाला) कोई भी डेटा मौजूद नहीं होता है। क्योंकि वहां कुछ भी गलत नहीं है, इसलिए JavaScript मान लेता है कि सब कुछ सही है और true (सही) रिटर्न करता है। इसी स्थिति को Vacuous Truth कहते हैं।

उदाहरण (Example in JavaScript):

मान लीजिए आपके पास एक खाली टोकरी (empty array) है और आप पूछते हैं, "क्या इस टोकरी के सभी सेब लाल हैं?"
javascript
const apples = []; // टोकरी खाली है

// जांच रहे हैं कि क्या सभी सेब लाल हैं
const allRed = apples.every(apple => apple.color === "red");

console.log(allRed); // आउटपुट: true
Use code with caution.
• ऐसा क्यों हुआ? क्योंकि टोकरी में एक भी ऐसा सेब नहीं है जो लाल न हो (यानी कोई भी सेब इस शर्त को तोड़ता या violate नहीं करता है)।
• इसलिए कंप्यूटर बिना किसी सबूत के इसे सही (true) मान लेता है।
