# 4. Accessing Array Elements

Array indexing starts from zero.

```
let fruits = ["Apple", "Banana", "Mango", "Orange"];
```

Array index visualization

# 0

Apple

# 1

Banana

# 2

Mango

# 3

Orange

Index starts at 0, not 1.

```
console.log(fruits[0]); // Apple
console.log(fruits[1]); // Banana
console.log(fruits[2]); // Mango
console.log(fruits[3]); // Orange
```

### Accessing the last element

```
console.log(fruits[fruits.length - 1]); // Orange
```

Why `length - 1`?

There are 4 elements, but their indexes are `0, 1, 2, 3`.

So:

```
fruits.length     // 4
fruits.length - 1 // 3
```

### at() method

```
console.log(fruits.at(0));  // Apple
console.log(fruits.at(-1)); // Orange
console.log(fruits.at(-2)); // Mango
```

Negative indexes count from the end.

Remember: `fruits[-1]` does not access the last array element. It accesses an ordinary property named `"-1"`.

```
console.log(fruits[-1]); // undefined
```
