# 8. splice() – Add, Remove and Replace Elements

`splice()` is one of the most important array methods.

Syntax:

```
array.splice(start, deleteCount, item1, item2, ...);
```

It changes the original array.

### Case 1: Remove elements

```
let arr = [10, 20, 30, 40, 50];

arr.splice(1, 2);

console.log(arr); // [10, 40, 50]
```

Explanation:

- Start at index 1.
- Delete 2 elements.
- Removes `20` and `30`.

### Case 2: Add elements

```
let arr = [10, 20, 40];

arr.splice(2, 0, 30);

console.log(arr); // [10, 20, 30, 40]
```

Why `0`?

Because we want to delete zero elements and only insert `30`.

### Case 3: Replace elements

```
let arr = [10, 20, 30];

arr.splice(1, 1, 200);

console.log(arr); // [10, 200, 30]
```

Explanation:

- Start at index 1.
- Delete one element (`20`).
- Insert `200` at the same position.

### Case 4: Negative index

```
let arr = [10, 20, 30, 40];

arr.splice(-1, 1);

console.log(arr); // [10, 20, 30]
```

`-1` means start from the last position.

### Case 5: Return value

```
let arr = [10, 20, 30, 40];

let removed = arr.splice(1, 2);

console.log(arr);     // [10, 40]
console.log(removed); // [20, 30]
```

The original array contains the remaining elements, while the return value contains removed elements.
