# 11. includes() – Check Whether an Element Exists

Returns `true` or `false`.

```
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.includes("Banana")); // true
console.log(fruits.includes("Orange")); // false
```

Why?

It checks whether the specified value exists in the array.

```
let numbers = [10, 20, 30];

console.log(numbers.includes(20)); // true
console.log(numbers.includes("20")); // false
```

Because number `20` and string `"20"` are different values.

### includes() with starting index

```
let arr = [10, 20, 30, 20];

console.log(arr.includes(20, 2)); // true
console.log(arr.includes(20, 3)); // true
console.log(arr.includes(20, 4)); // false
```

Syntax:

```
array.includes(value, fromIndex);
```
