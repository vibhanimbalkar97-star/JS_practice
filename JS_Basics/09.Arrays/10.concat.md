# 10. concat() – Combine Arrays

Used to combine two or more arrays.

```
let a = [10, 20];
let b = [30, 40];

let result = a.concat(b);

console.log(result); // [10, 20, 30, 40]
console.log(a);      // [10, 20]
```

Combine multiple arrays:

```
let a = [1, 2];
let b = [3, 4];
let c = [5, 6];

console.log(a.concat(b, c));
// [1, 2, 3, 4, 5, 6]
```

Why use `concat()`?

It creates a new combined array without modifying the original arrays.

Alternative using spread:

```
let result = [...a, ...b];
```
