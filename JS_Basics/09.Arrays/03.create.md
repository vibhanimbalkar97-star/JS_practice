# 3. Creating Arrays

There are multiple ways to create arrays.

### Method 1: Array literal (recommended)

```
let numbers = [10, 20, 30, 40];
```

This is the simplest and most commonly used method.

### Method 2: Empty array

```
let arr = [];

arr[0] = 10;
arr[1] = 20;

console.log(arr); // [10, 20]
```

### Method 3: Array constructor

```
let arr = new Array(10, 20, 30);

console.log(arr); // [10, 20, 30]
```

Important tricky example:

```
let arr = new Array(5);

console.log(arr.length); // 5
console.log(arr); 
```

This creates an array with 5 empty slots, not an array containing the number `5`.

Compare:

```
let a = new Array(5);
let b = [5];

console.log(a.length); // 5
console.log(b.length); // 1
```

Interview trick: Prefer `[]` for normal array creation because `new Array()` has special behavior when given one numeric argument.

### Method 4: Array.of()

```
let arr = Array.of(5);

console.log(arr); // [5]
```

Unlike `new Array(5)`, `Array.of(5)` creates one element containing `5`.

### Method 5: Array.from()

Creates a new array from an iterable or array-like object.

```
let str = "hello";

let arr = Array.from(str);

console.log(arr); // ["h", "e", "l", "l", "o"]
```

You can also generate arrays:

```
let numbers = Array.from({ length: 5 }, (_, index) => index + 1);

console.log(numbers); // [1, 2, 3, 4, 5]
```

Why does it work?

- `length: 5` means create 5 positions.
- `_` represents the current element (unused here).
- `index` represents the current index.
- `index + 1` generates values from 1 to 5.
