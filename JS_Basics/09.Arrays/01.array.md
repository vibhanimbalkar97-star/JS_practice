# 1. What is an Array?

An array is a data structure used to store multiple values inside a single variable.

Without an array:

```
let student1 = "Rahul";
let student2 = "Priya";
let student3 = "Amit";
```

With an array:

```
let students = ["Rahul", "Priya", "Amit"];
```

Why do we use arrays?

Instead of creating multiple variables, we can store and manage multiple values together.

```
console.log(students);
```

Output:

```
["Rahul", "Priya", "Amit"]
```
