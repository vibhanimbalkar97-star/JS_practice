# 12. indexOf() and lastIndexOf()

These methods return the index of an element.

### indexOf()

Returns the first matching index.

```
let arr = [10, 20, 30, 20];

console.log(arr.indexOf(20)); // 1
console.log(arr.indexOf(50)); // -1
```

Why `-1`?

It means the element was not found.

### lastIndexOf()

Returns the last matching index.

```
let arr = [10, 20, 30, 20];

console.log(arr.lastIndexOf(20)); // 3
```

### Difference

| Method          | Meaning               |
| --------------- | --------------------- |
| `indexOf()`     | First matching index  |
| `lastIndexOf()` | Last matching index   |
| `includes()`    | Returns true or false |

Important:

```
let arr = [NaN, 10];

console.log(arr.includes(NaN)); // true
console.log(arr.indexOf(NaN));  // -1
```

Why?

`includes()` uses SameValueZero comparison, which can match `NaN`. `indexOf()` uses strict equality, and `NaN === NaN` is false.

Comparison Across Equality Algorithms

The three primary non-coercing equality checks in JavaScript differ only in how they handle signed zeros and NaN.

Comparison Type	+0 vs -0	NaN vs NaN	5 vs '5'	Primary Use Case
Strict Equality (===)	true	false	false	General comparisons, indexOf(), switch
SameValue (Object.is)	false	true	false	Exact value identity, property descriptors
SameValueZero	true	true	false	Set, Map, .includes()
