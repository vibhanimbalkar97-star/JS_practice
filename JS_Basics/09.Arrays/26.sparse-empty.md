# 38. Sparse Arrays and Empty Slots

A sparse array contains empty slots between its indexes.

```
let arr = [10, , 30];

console.log(arr.length); // 3
console.log(arr[1]);     // undefined
```

But an empty slot is not exactly the same as an element containing `undefined`.

```
let a = [10, , 30];
let b = [10, undefined, 30];

console.log(1 in a); // false
console.log(1 in b); // true
```

Why?

- `a` has an empty slot at index 1.
- `b` has an actual element with value `undefined`.

### How array methods handle empty slots

```
let arr = [10, , 30];

arr.forEach(x => console.log(x));
```

Output:

```
10
30
```

`forEach()` skips empty slots.

But:

```
let result = arr.map(x => x * 2);

console.log(result);
// [20, empty, 60]
```

`map()` preserves the empty slot.

Important: `for...of` reads an empty slot as `undefined`.

```
for (let value of arr) {
  console.log(value);
}
```

Output:

```
10
undefined
30
```

Interview rule: Empty slots, `undefined` elements and `null` are not interchangeable.



Behavioral Comparison


Feature / Operation	Empty Slot ([ , ])	undefined ([undefined])	null ([null])
Index exists (0 in arr)	false	true	true
Direct read (arr[0])	undefined	undefined	null
Strict equality (=== undefined)	true	true	false
forEach, map, filter, reduce	Skipped (callback never runs)	Visited (passes undefined)	Visited (passes null)
for...of & Spread ([...arr])	Visits as undefined (fills hole)	Visits as undefined	Visits as null
JSON.stringify(arr)	Serializes as "null"	Serializes as "null"	Serializes as "null"
Default parameters ((x = 1) => x)	Triggers default (1)	Triggers default (1)	Keeps null
