# 5. Updating Array Elements

Arrays are mutable, which means we can change their elements.

```
let fruits = ["Apple", "Banana", "Mango"];

fruits[1] = "Orange";

console.log(fruits);
```

Output:

```
["Apple", "Orange", "Mango"]
```

Why?

Index `1` contains `"Banana"`. Assigning a new value replaces that element.

### Updating multiple elements

```
let numbers = [10, 20, 30, 40];

numbers[0] = 100;
numbers[2] = 300;

console.log(numbers); // [100, 20, 300, 40]
```

### What happens if we use an index outside the current range?

```
let arr = [10, 20];

arr[5] = 60;

console.log(arr);
console.log(arr.length);
```

Output:

```
[10, 20, empty × 3, 60]
6
```

There are empty slots at indexes 2, 3 and 4.

Interview rule: Assigning to an index beyond the current end increases `length` and creates sparse slots.
