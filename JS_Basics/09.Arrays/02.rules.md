## 2. Important rules of JavaScript arrays

| Rule                | Explanation                                         |
| ------------------- | --------------------------------------------------- |
| Ordered             | Elements maintain their positions.                  |
| Zero-based indexing | First element starts at index `0`.                  |
| Dynamic size        | We can add or remove elements.                      |
| Mixed data types    | Can store strings, numbers, booleans, objects, etc. |
| Mutable             | We can change array elements.                       |
| Duplicate values    | Duplicate elements are allowed.                     |
| Reference type      | Arrays are objects in JavaScript.                   |

Example:

```
let arr = ["Hello", 100, true, null, { name: "Raj" }];

console.log(arr);
console.log(typeof arr);
```

Output:

```
["Hello", 100, true, null, { name: "Raj" }]
"object"
```

Why is `typeof []` equal to `"object"`?

Because JavaScript arrays are a special type of object.

To check whether a value is an array:

```
console.log(Array.isArray([1, 2, 3])); // true
console.log(Array.isArray({ a: 1 })); // false
```

Use `Array.isArray()` instead of `typeof` to identify arrays.
