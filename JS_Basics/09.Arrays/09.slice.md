# 9. slice() – Extract Elements Without Changing Original

Syntax:

```
array.slice(start, end);
```

Important: The end index is excluded.

```
let arr = [10, 20, 30, 40, 50];

let result = arr.slice(1, 4);

console.log(result); // [20, 30, 40]
console.log(arr);    // [10, 20, 30, 40, 50]
```

Why is `50` not included?

Because `slice(1, 4)` includes indexes 1, 2 and 3, but excludes index 4.

### Copy entire array

```
let arr = [10, 20, 30];

let copy = arr.slice();

console.log(copy); // [10, 20, 30]
```

### Negative indexes

```
let arr = [10, 20, 30, 40, 50];

console.log(arr.slice(-2)); // [40, 50]
```

### slice vs splice

| slice()                  | splice()                       |
| ------------------------ | ------------------------------ |
| Extracts elements        | Adds/removes/replaces elements |
| Does not change original | Changes original               |
| End index excluded       | Uses delete count              |
| Returns extracted array  | Returns removed elements       |

Remember: `slice()` = copy/extract. `splice()` = modify.
