## 6. Boolean conversion using `Boolean()`

JavaScript has two groups: truthy and falsy values.

### Falsy values

| Value        | Example              | Output  |
| ------------ | -------------------- | ------- |
| `false`      | `Boolean(false)`     | `false` |
| `0`          | `Boolean(0)`         | `false` |
| `-0`         | `Boolean(-0)`        | `false` |
| `0n`         | `Boolean(0n)`        | `false` |
| Empty string | `Boolean("")`        | `false` |
| `null`       | `Boolean(null)`      | `false` |
| `undefined`  | `Boolean(undefined)` | `false` |
| `NaN`        | `Boolean(NaN)`       | `false` |

### Truthy values

| Value            | Example                 | Output |
| ---------------- | ----------------------- | ------ |
| Non-zero number  | `Boolean(5)`            | `true` |
| Negative number  | `Boolean(-5)`           | `true` |
| Non-empty string | `Boolean("hello")`      | `true` |
| String `"false"` | `Boolean("false")`      | `true` |
| String `"0"`     | `Boolean("0")`          | `true` |
| Space string     | `Boolean(" ")`          | `true` |
| Empty array      | `Boolean([])`           | `true` |
| Empty object     | `Boolean({})`           | `true` |
| Function         | `Boolean(function(){})` | `true` |

Interview rule: In JavaScript, empty arrays and empty objects are truthy. This is different from Python.
