## 2. Number conversion using `Number()`

| Value             | Example             | Output |
| ----------------- | ------------------- | ------ |
| Integer string    | `Number("25")`      | `25`   |
| Decimal string    | `Number("2.5")`     | `2.5`  |
| Empty string      | `Number("")`        | `0`    |
| Whitespace string | `Number(" ")`       | `0`    |
| Boolean true      | `Number(true)`      | `1`    |
| Boolean false     | `Number(false)`     | `0`    |
| `null`            | `Number(null)`      | `0`    |
| `undefined`       | `Number(undefined)` | `NaN`  |
| Invalid string    | `Number("hello")`   | `NaN`  |
| Number with units | `Number("12px")`    | `NaN`  |
| Binary string     | `Number("0b101")`   | `5`    |
| Hex string        | `Number("0xA")`     | `10`   |

### Rule

`Number()` tries to convert the entire value into a number. If it cannot, it returns `NaN` instead of throwing an error.
