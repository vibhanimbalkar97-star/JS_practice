## 16. Common conversion errors

| Example               | Result        | Reason                                          |
| --------------------- | ------------- | ----------------------------------------------- |
| `Number("abc")`       | `NaN`         | Invalid number                                  |
| `parseInt("abc")`     | `NaN`         | No integer at the beginning                     |
| `1 + undefined`       | `NaN`         | `undefined` converts to `NaN`                   |
| `null.toString()`     | `TypeError`   | `null` has no method                            |
| `Symbol("x") + "hi"`  | `TypeError`   | Symbol cannot be implicitly converted to string |
| `10n + 10`            | `TypeError`   | BigInt and Number cannot be mixed in arithmetic |
| `JSON.parse("hello")` | `SyntaxError` | Invalid JSON                                    |

Remember the difference:

| Result        | Meaning                                                          |
| ------------- | ---------------------------------------------------------------- |
| `NaN`         | The conversion or calculation produced an invalid numeric result |
| `TypeError`   | The operation is not allowed for that type                       |
| `SyntaxError` | The input text has invalid syntax                                |

## 17. Quick interview revision: rules to memorize

| Rule                                             | Example            | Output     |
| ------------------------------------------------ | ------------------ | ---------- |
| Number + Number → Number                         | `2 + 3`            | `5`        |
| Number + String → String                         | `2 + "3"`          | `"23"`     |
| String - Number → Number                         | `"5" - 2`          | `3`        |
| String \* Number → Number                        | `"5" * 2`          | `10`       |
| `true` converts to `1`                           | `true + 2`         | `3`        |
| `false` converts to `0`                          | `false + 2`        | `2`        |
| `null` converts to `0` in numeric conversion     | `null + 2`         | `2`        |
| `undefined` converts to `NaN`                    | `undefined + 2`    | `NaN`      |
| Empty string is falsy                            | `Boolean("")`      | `false`    |
| String `"false"` is truthy                       | `Boolean("false")` | `true`     |
| Empty array is truthy                            | `Boolean([])`      | `true`     |
| Empty object is truthy                           | `Boolean({})`      | `true`     |
| `==` can convert types                           | `5 == "5"`         | `true`     |
| `===` does not convert types                     | `5 === "5"`        | `false`    |
| `NaN` is not equal to itself                     | `NaN === NaN`      | `false`    |
| Ordinary integers and decimals are both `number` | `typeof 5.5`       | `"number"` |
| Array `typeof` is object                         | `typeof []`        | `"object"` |
| `+` may concatenate                              | `"1" + 2 + 3`      | `"123"`    |
| Arithmetic is evaluated left to right            | `1 + 2 + "3"`      | `"33"`     |

### One final trick: order matters

```
console.log("1" + 2 + 3); // "123"
console.log(1 + 2 + "3"); // "33"
console.log(1 + "2" + 3); // "123"
console.log(1 + 2 + 3);   // 6
```

The most important concept: JavaScript does not automatically convert every value in the same way. The operator determines how conversion happens.
