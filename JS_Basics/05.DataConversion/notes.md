# JavaScript Type Conversion & Type Casting — Beginner Interview Notes

In JavaScript, type conversion means changing a value from one data type to another.

There are two ways:

| Type                           | Meaning                           | Example             |
| ------------------------------ | --------------------------------- | ------------------- |
| Implicit conversion (coercion) | JavaScript converts automatically | `"5" - 2` → `3`     |
| Explicit conversion (casting)  | We convert manually               | `Number("5")` → `5` |

Unlike Python, JavaScript often converts values automatically during arithmetic and comparisons. These rules are very common in output-based interview questions.
