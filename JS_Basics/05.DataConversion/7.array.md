## 7. Type conversion with arrays

| Example                | Output   | Explanation                                    |
| ---------------------- | -------- | ---------------------------------------------- |
| `Number([])`           | `0`      | Empty array converts to empty string, then `0` |
| `Number([5])`          | `5`      | Single item becomes `"5"`                      |
| `Number([1, 2])`       | `NaN`    | `"1,2"` is not a valid number                  |
| `String([1, 2])`       | `"1,2"`  | Array items are joined with commas             |
| `String([1, null, 3])` | `"1,,3"` | `null` becomes empty in array stringification  |
| `Boolean([])`          | `true`   | Arrays are truthy                              |
| `Boolean([0])`         | `true`   | Non-empty array is truthy                      |

### Array addition

```
console.log([1, 2] + [3, 4]);
```

Output:

```
"1,23,4"
```

Why?

```
[1, 2]  -> "1,2"
[3, 4]  -> "3,4"

"1,2" + "3,4" -> "1,23,4"
```

### Array subtraction

```
console.log([5] - 2); // 3
console.log([1, 2] - 2); // NaN
```

`-` tries to convert the array to a number.
