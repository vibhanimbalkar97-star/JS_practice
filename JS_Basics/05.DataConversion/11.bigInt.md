## 14. BigInt conversion rules

`BigInt` is used for integers larger than the safe range of ordinary JavaScript numbers.

| Example         | Output      | Rule                                       |
| --------------- | ----------- | ------------------------------------------ |
| `BigInt(10)`    | `10n`       | Converts integer to BigInt                 |
| `BigInt("123")` | `123n`      | Converts integer string                    |
| `10n + 5n`      | `15n`       | BigInt arithmetic                          |
| `10n + 5`       | `TypeError` | Cannot mix BigInt and Number in arithmetic |
| `10n === 10`    | `false`     | Different types                            |
| `10n == 10`     | `true`      | Loose equality compares values             |

```
console.log(typeof 10n); // "bigint"
```

Rule: Use `Number` with `Number`, and `BigInt` with `BigInt` for arithmetic.
