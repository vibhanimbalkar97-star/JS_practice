## 8. `null`, `undefined`, and `NaN` conversion rules

| Expression           | Output        | Rule                             |
| -------------------- | ------------- | -------------------------------- |
| `Number(null)`       | `0`           | `null` converts to zero          |
| `Number(undefined)`  | `NaN`         | Cannot convert to a valid number |
| `Number(NaN)`        | `NaN`         | Remains `NaN`                    |
| `String(null)`       | `"null"`      | String representation            |
| `String(undefined)`  | `"undefined"` | String representation            |
| `Boolean(null)`      | `false`       | Falsy                            |
| `Boolean(undefined)` | `false`       | Falsy                            |
| `Boolean(NaN)`       | `false`       | Falsy                            |
| `typeof null`        | `"object"`    | Historical JavaScript behavior   |
| `typeof undefined`   | `"undefined"` | Its own type                     |
| `typeof NaN`         | `"number"`    | `NaN` is a numeric value         |

### `NaN` rules

```
console.log(NaN === NaN);       // false
console.log(Number.isNaN(NaN)); // true
console.log(Number.isNaN("hi")); // false
console.log(isNaN("hi"));        // true
```

| Function              | Rule                                               |
| --------------------- | -------------------------------------------------- |
| `Number.isNaN(value)` | Checks if the value itself is `NaN`; no conversion |
| `isNaN(value)`        | Converts the value to a number first, then checks  |
