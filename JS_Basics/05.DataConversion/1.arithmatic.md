## 1. Basic arithmetic conversion rules

| Operation            | Example         | Output | Rule                                    |
| -------------------- | --------------- | ------ | --------------------------------------- |
| Number + Number      | `5 + 2`         | `7`    | Addition                                |
| Number + String      | `5 + "2"`       | `"52"` | `+` converts to string and concatenates |
| String + Number      | `"5" + 2`       | `"52"` | Concatenation                           |
| String - Number      | `"5" - 2`       | `3`    | String converted to number              |
| String \* Number     | `"5" * 2`       | `10`   | String converted to number              |
| String / Number      | `"10" / 2`      | `5`    | String converted to number              |
| Number + Boolean     | `5 + true`      | `6`    | `true` becomes `1`                      |
| Number + Boolean     | `5 + false`     | `5`    | `false` becomes `0`                     |
| Number + `null`      | `5 + null`      | `5`    | `null` becomes `0`                      |
| Number + `undefined` | `5 + undefined` | `NaN`  | `undefined` becomes `NaN`               |
| Number + `NaN`       | `5 + NaN`       | `NaN`  | Arithmetic result stays `NaN`           |

Important: `+` is special. If either operand becomes a string, concatenation may happen. Other arithmetic operators usually convert values to numbers.
