## 4. Arithmetic: JavaScript does not have separate `int` and `float` types

In Python, `int + float` gives a `float`. In JavaScript, ordinary numbers are all of type `number`.

| Operation            | Example             | Output     | Rule                             |
| -------------------- | ------------------- | ---------- | -------------------------------- |
| Integer + Integer    | `5 + 2`             | `7`        | Result is `number`               |
| Integer + Decimal    | `5 + 2.5`           | `7.5`      | Both are `number`                |
| Decimal + Decimal    | `1.2 + 2.3`         | `3.5`      | Both are `number`                |
| Multiplication       | `2 * 2.5`           | `5`        | Result is still `number`         |
| Division             | `5 / 2`             | `2.5`      | `/` can return decimal           |
| Floor-like division  | `Math.floor(5 / 2)` | `2`        | Use `Math.floor()` to round down |
| Remainder            | `5 % 2`             | `1`        | Gives remainder                  |
| Power                | `2 ** 3`            | `8`        | Exponent operator                |
| Division by zero     | `5 / 0`             | `Infinity` | Does not throw an error          |
| Zero divided by zero | `0 / 0`             | `NaN`      | Invalid numeric result           |

### Why does `0.1 + 0.2` produce a strange result?

```
console.log(0.1 + 0.2);
```

Output:

```
0.30000000000000004
```

JavaScript uses floating-point numbers. Some decimal fractions cannot be represented exactly in binary.

| Example                 | Output     |
| ----------------------- | ---------- |
| `0.1 + 0.2 === 0.3`     | `false`    |
| `Number.isInteger(5)`   | `true`     |
| `Number.isInteger(5.2)` | `false`    |
| `typeof 5`              | `"number"` |
| `typeof 5.2`            | `"number"` |
