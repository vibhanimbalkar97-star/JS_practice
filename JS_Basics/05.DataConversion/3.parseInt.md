## 3. `parseInt()` and `parseFloat()`

| Example               | Output | Rule                        |
| --------------------- | ------ | --------------------------- |
| `parseInt("12.8")`    | `12`   | Reads integer portion       |
| `parseFloat("12.8")`  | `12.8` | Reads decimal number        |
| `parseInt("12px")`    | `12`   | Stops at invalid character  |
| `parseFloat("3.5kg")` | `3.5`  | Stops at invalid character  |
| `Number("12px")`      | `NaN`  | Entire string must be valid |
| `parseInt("hello")`   | `NaN`  | No valid number at start    |
| `parseInt("101", 2)`  | `5`    | Parses as binary            |
| `parseInt("A", 16)`   | `10`   | Parses as hexadecimal       |

Interview difference:

```
Number("12.8");     // 12.8
parseInt("12.8");   // 12
parseFloat("12.8"); // 12.8
