## 15. `typeof` rules — memorize these

| Value          | `typeof` output |
| -------------- | --------------- |
| `10`           | `"number"`      |
| `10.5`         | `"number"`      |
| `NaN`          | `"number"`      |
| `"hello"`      | `"string"`      |
| `true`         | `"boolean"`     |
| `undefined`    | `"undefined"`   |
| `null`         | `"object"`      |
| `[]`           | `"object"`      |
| `{}`           | `"object"`      |
| `function(){}` | `"function"`    |
| `10n`          | `"bigint"`      |
| `Symbol("id")` | `"symbol"`      |

To check an array:

```
console.log(Array.isArray([])); // true
```

Because `typeof []` returns `"object"`, use `Array.isArray()` to identify arrays.
