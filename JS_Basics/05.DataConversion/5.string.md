## 5. String conversion using `String()`

| Value       | Example             | Output              |
| ----------- | ------------------- | ------------------- |
| Number      | `String(25)`        | `"25"`              |
| Decimal     | `String(2.5)`       | `"2.5"`             |
| Boolean     | `String(true)`      | `"true"`            |
| `null`      | `String(null)`      | `"null"`            |
| `undefined` | `String(undefined)` | `"undefined"`       |
| `NaN`       | `String(NaN)`       | `"NaN"`             |
| Array       | `String([1, 2, 3])` | `"1,2,3"`           |
| Empty array | `String([])`        | `""`                |
| Object      | `String({})`        | `"[object Object]"` |

### Other ways to convert to a string

| Method           | Example           | Output |
| ---------------- | ----------------- | ------ |
| `String()`       | `String(10)`      | `"10"` |
| `.toString()`    | `(10).toString()` | `"10"` |
| Template literal | `` `${10}` ``     | `"10"` |
| Concatenation    | `10 + ""`         | `"10"` |

Important difference:

```
String(null);      // "null"
null.toString();   // TypeError
```

`String()` can convert `null` and `undefined`. But those values do not have a `.toString()` method.
