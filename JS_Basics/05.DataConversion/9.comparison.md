## 9. Comparison conversion rules

### Relational operators: `>`, `<`, `>=`, `<=`

| Example         | Output  | Rule                                        |
| --------------- | ------- | ------------------------------------------- |
| `5 > "3"`       | `true`  | String converted to number                  |
| `"10" > 5`      | `true`  | String converted to number                  |
| `"10" > "2"`    | `false` | Both strings compared lexicographically     |
| `"2" > "10"`    | `true`  | String comparison is character-by-character |
| `true > false`  | `true`  | `true` becomes `1`, `false` becomes `0`     |
| `null >= 0`     | `true`  | `null` becomes `0`                          |
| `undefined > 0` | `false` | Conversion results in `NaN`                 |

Remember: If both operands are strings, JavaScript compares them as strings.

```
console.log("20" > "100"); // true
```

It compares the first characters: `"2"` is greater than `"1"`.

### Equality operators

| Example              | Output  | Rule                                  |
| -------------------- | ------- | ------------------------------------- |
| `5 == "5"`           | `true`  | Loose equality converts types         |
| `5 === "5"`          | `false` | Strict equality checks type and value |
| `0 == false`         | `true`  | Loose equality converts boolean       |
| `0 === false`        | `false` | Different types                       |
| `null == undefined`  | `true`  | Special loose-equality rule           |
| `null === undefined` | `false` | Different types                       |
| `"" == 0`            | `true`  | Empty string converts to zero         |
| `"" === 0`           | `false` | Different types                       |
| `NaN == NaN`         | `false` | `NaN` is never equal to itself        |

Interview recommendation: Prefer `===` and `!==` unless you specifically need loose equality.

## 10. Logical operators also perform conversion

\| Example | Output | Rule |\
\|---|---|---|\
\| `true && "hello"` | `"hello"` | `&&` returns the last truthy value if all are truthy |\
\| `false && "hello"` | `false` | Stops at first falsy value |\
\| `0 || "hello"` | `"hello"` | `||` returns first truthy value |\
\| `"Hi" || "Hello"` | `"Hi"` | First value is truthy |\
\| `"" || "default"` | `"default"` | Empty string is falsy |\
\| `"Hi" && 5` | `5` | Both are truthy; returns last value |\
\| `!5` | `false` | `!` converts to Boolean and reverses it |\
\| `!!"hello"` | `true` | Double `!` converts to Boolean |

### `||` versus `??`

\| Example | Output | Rule |\
\|---|---|---|\
\| `0 || 10` | `10` | `||` uses fallback for any falsy value |\
\| `0 ?? 10` | `0` | `??` uses fallback only for `null` or `undefined` |\
\| `null ?? 10` | `10` | Nullish value |\
\| `undefined ?? 10` | `10` | Nullish value |\
\| `false ?? 10` | `false` | `false` is not nullish |
