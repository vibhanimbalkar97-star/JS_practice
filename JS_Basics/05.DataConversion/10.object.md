## 11. Object conversion rules

| Example          | Output                             | Explanation                                |
| ---------------- | ---------------------------------- | ------------------------------------------ |
| `String({})`     | `"[object Object]"`                | Default object string representation       |
| `Number({})`     | `NaN`                              | Object cannot become a valid number        |
| `Boolean({})`    | `true`                             | Objects are truthy                         |
| `String({a: 1})` | `"[object Object]"`                | Default representation                     |
| `({} + {})`      | `"[object Object][object Object]"` | Objects convert to strings in this context |

If you want to convert an object to JSON text, use:

```
const user = { name: "Sam", age: 25 };

console.log(JSON.stringify(user));
// '{"name":"Sam","age":25}'
```

To convert JSON text back into an object:

```
const text = '{"name":"Sam","age":25}';

console.log(JSON.parse(text));
// { name: "Sam", age: 25 }
```

| Function                 | Conversion           |
| ------------------------ | -------------------- |
| `JSON.stringify(object)` | Object → JSON string |
| `JSON.parse(string)`     | JSON string → object |

Note: `JSON.parse()` throws a `SyntaxError` if the input is invalid JSON.

## 12. Unary plus and minus

| Example    | Output | Rule                             |
| ---------- | ------ | -------------------------------- |
| `+"5"`     | `5`    | Unary `+` converts to number     |
| `+"hello"` | `NaN`  | Invalid numeric string           |
| `+true`    | `1`    | Boolean conversion               |
| `+null`    | `0`    | Null conversion                  |
| `+" "`     | `0`    | Whitespace string becomes zero   |
| `-"5"`     | `-5`   | Converts to number, then negates |
| `-"hello"` | `NaN`  | Invalid numeric string           |

```
let value = "20";

console.log(+value);       // 20
console.log(typeof +value); // "number"
```

Unary `+` is a short way to write `Number(value)`.

## 13. Bitwise operators convert values to 32-bit integers

These are a little more advanced, but sometimes appear in output questions.

| Operator         | Example   | Output |
| ---------------- | --------- | ------ |
| AND `&`          | `5 & 1`   | `1`    |
| OR `\\|`         | `5 \\| 1` | `5`    |
| XOR `^`          | `5 ^ 1`   | `4`    |
| Left shift `<<`  | `5 << 1`  | `10`   |
| Right shift `>>` | `5 >> 1`  | `2`    |
| Bitwise NOT `~`  | `~5`      | `-6`   |

For ordinary `number` values, bitwise operations convert them to 32-bit integer representations.

```
console.log(5.8 & 1); // 1
```

The decimal portion is discarded during the bitwise integer conversion.
